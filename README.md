# Gains Tracker

A local-only personal strength training and catching (baseball/softball) progress
tracker. All data lives in your browser (IndexedDB via Dexie) — nothing is sent
to a server. Log lifts and catching drills, review your history, track PRs,
and view progress charts. Data can be exported to and imported from a JSON
backup file from the Settings screen.

## Development

```
npm install
npm run dev
```

## Testing

```
npm test
```

## Build

```
npm run build
```
